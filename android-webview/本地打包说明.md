# 小宠打卡 · 本地离线打包 APK（无需 GitHub / 无需服务器）

这个安卓工程把 `index.html / styles.css / app.js` 直接打包进 APK，
**完全离线运行，不需要 GitHub Pages，也不需要任何服务器**。
代价：编译出 `.apk` 必须在你自己的电脑上用 Android Studio 完成一次（免费）。

## 1. 安装 Android Studio（一次性，约 1~3 GB）

下载：https://developer.android.com/studio
安装时一路下一步即可（会顺带装好 Android SDK）。

## 2. 打开工程并编译

1. 打开 Android Studio → **Open** → 选择本文件夹 `android-webview`。
2. 第一次会下载 Gradle 和编译依赖，等底部状态栏同步完成（约几分钟）。
   - 若提示 "Gradle wrapper not found"，选 **Use default Gradle wrapper** 或让它自动下载即可。
3. 菜单 **Build → Build APK(s)**（或 **Make Project**）。
4. 编译完成后，APK 在：
   `android-webview/app/build/outputs/apk/debug/app-debug.apk`

> debug 签名就**可以直接安装**，不用自己生成 keystore。
> 只有要上架应用商店时才需要正式签名。

## 3. 安装到手机

1. 把 `app-debug.apk` 传到手机（微信文件传输 / 数据线 / U盘）。
2. 手机会提示“允许安装未知来源应用”，在设置里授权该来源。
3. 点击 APK 完成安装，桌面出现“小宠打卡”图标。

## 4. 以后更新内容

离线内置版：改完 `index.html / styles.css / app.js` 后，**重新拷贝到
`app/src/main/assets/` 并重新 Build APK** 才能生效。
（相比“GitHub 线上版”不能自动更新，这是离线方案的取舍。）

## 5. 与“GitHub 线上版”的区别

| | 本地离线版（本工程） | GitHub 线上版（TWA） |
|---|---|---|
| 需要 GitHub | 不需要 | 需要 |
| 需要联网 | 不需要（可纯离线） | 运行时需联网 |
| 内容更新 | 重新打包 APK | 改完 push 自动生效 |
| 本机要装什么 | Android Studio（一次性） | 什么都不用装（云端编译） |
| Service Worker / 浏览器“添加到主屏幕” | 不生效（已是原生 App） | 生效 |

## 进阶（可选）

- **换图标**：替换 `app/src/main/res/drawable/ic_launcher_foreground.xml`（矢量），
  或放 PNG 并改 `AndroidManifest.xml` 里的 `android:icon`。
- **隐藏顶部状态栏**：已在 `styles.xml` 设为全屏；若想显示状态栏，删掉
  `<item name="android:windowFullscreen">true</item>`。
- **正式发布签名**：Build → Generate Signed Bundle / APK，按向导生成自己的 keystore。
